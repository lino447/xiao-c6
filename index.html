ESP32-C6 · BLE GATT
按下「搜尋並連線」後，瀏覽器會跳出附近裝置清單，選擇 XIAO-C6 再按「配對」即可。iPhone 請用 Bluefy 瀏覽器開啟本頁。
怎麼連線
  1. XIAO ESP32-C6 燒好 xiao_c6_ble.ino 並接上電源與繼電器。
  2. iPhone 用 Bluefy；電腦或 Android 用 Chrome / Edge。網址必須是 HTTPS 或 localhost。
  3. 按「搜尋並連線」，在清單裡選 XIAO-C6。
  4. 連上後回到「車輛」分頁操作。意外斷線會自動重試 3 次。
找不到裝置？
確認板子已通電、沒有被其他手機或電腦連著；iPhone 的「設定 → Bluefy → 藍牙」要允許。Safari、iOS 版 Chrome 和 Firefox 都不支援 Web Bluetooth。
